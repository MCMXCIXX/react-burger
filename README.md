# Stellar Burgers

Приложение для создания бургеров с drag-and-drop конструктором, системой авторизации и историей заказов.

## Технологии

- React 18
- Redux Toolkit
- React Router v7
- React DnD
- SCSS Modules
- @ya.praktikum/react-developer-burger-ui-components

## Запуск проекта

Установить зависимости:

```bash
npm install
```

Запустить в режиме разработки:

```bash
npm start
```

Приложение откроется на [http://localhost:3000](http://localhost:3000).

Для работы приложения необходимо запустить бэкенд на порту `4000`.

## Функциональность

- Конструктор бургеров с drag-and-drop
- Регистрация и авторизация пользователей
- Восстановление пароля через email
- Редактирование профиля пользователя
- Просмотр деталей ингредиентов
- Оформление заказов (только для авторизованных пользователей)
- Автоматическое обновление токена доступа
